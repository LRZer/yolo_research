# CUB双视图分类分离BN统计量实验协议

2026年10月2日。用户批准验证原图和局部图共用BN是否影响分类。本轮新增G6，只把两路BN的均值和方差分开，与已经严格验收的G4比较；不改写旧结果，不增加其他训练组。

## 研究问题和主对照

G4将原图和GT框局部图沿batch维拼接，一起经过共享ResNet50。G6仍沿batch维拼接，卷积、残差、池化和融合分类层完全保持共享；每个BN层把前半批原图和后半批局部图分别归一化。两套即时统计量和运行均值方差独立，但可学习缩放gamma和偏移beta使用同一参数对象，避免增加模型容量。

从相同种子初始化，两组全部可学习参数必须逐位相等，参数量都为24,327,432。G6有53个分离统计的BN位置；不同于两个独立ResNet，也不同于两套独立可学习BN参数。每次两卡前向，G4汇总32幅混合视图，G6每路汇总16幅视图；统计样本数变化属于本次分离干预本身，不能声称它与分布分离能够进一步独立归因。

主指标是固定第125轮官方test Top1，与G4的52.278219%比较；同时报告Top5、交叉熵、训练指标和耗时。G4固定末轮Top5为78.736624%，test loss为1.960690。G5空白全局加局部的64.687608%仅作背景参考，不是本轮主对照。best仅作次要观察，不依test成绩改变本轮超参数。

若G6改善，支持这一归一化适配在当前实现中有价值，不能证明G4与G5的全部差距都由BN造成；若不改善，也不证明所有全局信息无用。本轮只做单种子诊断，没有显著性承诺。

## 不变的输入和训练设置

图像处理直接复用冻结G4训练器：原图不缩放，居中补边500方形；按GT框无外扩裁剪，floor左上、ceil右下并裁边，局部长边等比例放大500、BICUBIC插值后补边。共同确定性翻转与亮度、对比度、饱和度增强先作用于原图，再产生两路。test无随机增强。六张批准预览必须逐像素一致，训练和test均使用GT框，是Oracle而非无标注部署。

| 设置 | 冻结值 |
| --- | --- |
| 数据和模型 | CUB官方train5994、test5794，200类，scratch ResNet50 |
| 随机种子 | 2005，全部共享参数初始值与G4相同 |
| 实际训练 | 125轮，原生循环正常退出 |
| 学习率 | 同200轮余弦计划前125项，warmup5，不是125轮余弦终点 |
| 优化器 | SGD，LR0.025，min LR1e-5，momentum0.9，weight decay0.0005 |
| 批次 | 全局有效64对，每卡micro8对，两卡累积4次 |
| 加载器 | workers4总计，每卡2；test每卡16对 |
| 损失 | 拼接4096维特征的200类交叉熵，无分支辅助损失 |
| 精度 | FP16 AMP，初始缩放1024，记录真实更新和跳步 |
| 资源 | 仅物理GPU2、3；CPU和内存绑定NUMA0，不调整他人作业 |
| 环境 | 既有yolo26 conda环境，依赖不修改 |

两卡的精确采样、94个更新组、尾组42对、梯度累积缩放和保存逻辑均直接复用G4冻结训练循环。拆分统计仍用SyncBatchNorm同步每一路的跨卡统计，不使用每卡独立BN。可学习BN参数使用原生BN核并共享对象，不引入额外低精度乘加实现。

## 代码核验和启动条件

新代码和配置独立保存，冻结的G4训练器、引擎、配置、CSV、best和last检查点SHA均核对；读取G4检查点的核验不写旧目录。CPU核验包括全部框和批准预览、精确采样、初始化相等、共享参数身份、独立缓冲区、逐路BN前向和梯度、运行统计、测试模式及保存加载一致性。

正式训练前先进行双卡小张量SyncBN数值测试，核对跨卡独立统计、共享参数DDP梯度、输入梯度和测试模式；再做与G4同样170张train、34张test、3次更新的全模型短测。必须全部参数和缓冲区跨卡一致，损失有限，更新3次且AMP无跳步。短测准确率不作研究结论。

每次启动重新检查GPU2、3 UUID、剩余显存、实测峰值加3000MiB余量、NUMA0保守内存预算、全机可用内存、PSI、当前boot EDAC和MCE/SIGBUS。上一boot Socket1 BERT重放仍是历史风险，不能称硬件已修复。资源不足则暂缓，不改变batch或迁移其他作业。管理器和训练各有独立防重复记录；失败不强行续训或杀正常进程。
