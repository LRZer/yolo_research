# 将背景平滑融入检测器：讨论用候选方向

记录：2026-09-24 约 04:10 CST。仅提出待验证假设与候选结构，不启动新训练，不宣称新颖性或性能提升。现有 VOC 安全背景模糊与原图基线 125 轮配对仍按既定协议执行。

## 已有证据及文献边界

- 本项目输入端单路径门控短训没有超过原图对照；旧完整 dev 审计小目标安全率仅85.15%，且门控/高斯处理带来明显推理开销。正在运行的长训尚无同预算原图基线结果，因此不能判断长期训练是否逆转。
- SET（CVPR 2025）已提出特征层层级背景平滑以抑制高频背景并提升微小目标检测；故“在检测器内部平滑背景”本身不是可独立主张的创新。原文：https://openaccess.thecvf.com/content/CVPR2025/html/Sun_SET_Spectral_Enhancement_for_Tiny_Object_Detection_CVPR_2025_paper.html
- BlurPool/抗混叠下采样是更早的通用低通先例，不应把平滑卷积或模糊下采样当作新机制。原文：https://proceedings.mlr.press/v97/zhang19a.html
- DREB-Net 的双流融合针对**输入已受运动模糊**的目标检测与复原；这是相关双流先例，但与本项目主动抑制清晰图像的背景纹理目标不同。原文：https://arxiv.org/abs/2410.17822

## 候选假设：保留原始信息的检测条件化频率路由

失败机制假设：输入端单路径模糊一旦压掉弱目标/上下文，后续 YOLO 无法取回细节；而平滑有时能降低背景纹理干扰。若两种信息都在检测器内部可用，网络可按位置、尺度及检测不确定性选择。

最小候选结构（尚未定案）：在 YOLOv8n 的一个早期特征尺度（优先 stride=8，后做尺度消融）同时保留原始特征 F 与廉价低通特征 B=G(F)。小型门控 A 从 F 预测平滑分支的增量权重，以零初始化残差融合 `F_out = F + h(A ⊙ (B−F))`；原始 F 始终有直接通路，不先破坏输入 RGB，也不复制一套完整 backbone。之后检测头仍预测同一批全部目标。该形式与现有注意/双流/SET 存在重叠，不能仅凭此结构宣称论文创新。

可能更有针对性的研究问题：**在有小目标漏保护风险时，怎样利用背景低频信息而保持原始检测证据可访问？** 候选约束是逐实例的高门控风险（特别是小目标）而非全图像素平均；同时避免以“远离标注框”强迫所有区域被平滑。检测损失必须决定低通分支是否真的有益；如果门控学为零，应接受负结果，不能为视觉效果强制平滑。

## 分阶段门槛

1. 先完成当前长训和同预算原图基线，独立审计 last.pt AP/类别/大小分层、门控保护率、延迟与硬件事件。若输入端方案不占优，明确以“信息不可逆丢失”作为待验证假设，而非既定解释。
2. 做低成本的特征层诊断：冻结基线，在一两个尺度插入无 GT 的固定低通/原样残差小扰动，观察候选/召回在小、中、大目标上的方向性；冻结模型的分布偏移使阴性诊断不能单独否定可训练融合。
3. 只在诊断支持且与 SET 的差别具体化后，做同预算小规模配对：原样继续训练、固定低通特征分支、学习门控但无逐实例安全约束、完整安全约束；固定数据/seed/轮数。逐项报告 AP、漏检、FLOPs、实测时延及误伤率，至少第二 seed/另一数据集、健康硬件复核后再谈论文。

当前优先级：作为下一研究路线候选，**尚不启动**。本路线的可发文性取决于明确失效机制、强对照、跨数据集与效率证据，不能因“更深地整合进 YOLO”而自动成立。
