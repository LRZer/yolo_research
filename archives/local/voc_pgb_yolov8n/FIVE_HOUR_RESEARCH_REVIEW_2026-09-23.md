## 已经完成的因果对照

VOC 开发集 1,655 张，YOLOv8n 随机初始化，seed2027，20 轮，
`imgsz=640`、`batch=64`。在相同的独立、未处理原图验证流程中：

| 训练处理 | 原图 mAP50–95 |
|---|---:|
| 不加模糊基线 | 0.161691 |
| 较弱 Oracle 背景模糊，仅训练阶段 | 0.161312 |
| 更强 Oracle 背景模糊，训练图像全处理 | 0.157440 |
| 更强 Oracle 背景模糊，随机处理约一半训练图像 | 0.161610 |

更强的处理确实改变了像素，但没有带来可确认的 VOC AP 提升；
全量处理反而降低约 0.00425 绝对 AP。半量处理接近持平，不是
胜出。各类别效果有明显异质性，不能以少数上涨类别替代总体
结论。20 轮、单种子的结论只排除这些具体短训配方，不能推断
所有背景操作均无效。证据见 `P1_STRONG_TRAINONLY_RESULTS_2026-09-23.md`、
`P1_STRONG_P50_TRAINONLY_RESULTS_2026-09-23.md` 与
`P1_CLASSWISE_RAW_ANALYSIS_2026-09-23.md`。

## 更强的 VisDrone 常规基线

采用官方来源 train 6,471 / val 548 图、转换后 val 38,759 个
目标框，YOLOv8n 随机初始化、seed2027、`batch=64`、125 轮。
已对三个完成的权重在同一批 548 张**原图**上独立复算：

| 模型/输入 | 内部转换标签 mAP50–95 | 解释 |
|---|---:|---|
| 标准 YOLOv8n / 640 | 0.170547 | 常规控制 |
| P2 检测头 / 640 | 0.198526 | 已知高分辨率头控制，不是本研究创新 |
| 标准 YOLOv8n / 960 | **0.232476** | 当前应优先比较的强常规基线 |

标准模型将输入从 640 提至 960，比 640 多 0.061929 绝对 AP，
全部十类均改善；P2/640 虽增加很低置信度的候选召回，但
未匹配候选更多，在最拥挤四分位甚至比标准 960 少匹配
124 个目标。分尺寸、分拥挤度诊断提示尺度、定位与排序/误检
都值得分开研究，但还没有证明某个单一因果机制。由于原始
VisDrone 的 ignored/other 区域在转换时被略去，此处 AP 是
**内部同口径指标，不是官方 VisDrone challenge AP**。原始 val
有 1,378 个 category-0 忽略区域标注，覆盖 340/548 张图。
参见 `VISDRONE_640_VS_960_RESULT_2026-09-23.md`、
`VISDRONE_P2_640_CONTROL_RESULT_2026-09-23.md`、
`VISDRONE_GT_CROWDING_DIAGNOSTIC_2026-09-23.md` 与
`VISDRONE_IGNORED_ANNOTATION_AUDIT_2026-09-23.md`。

## 方法与工程判断

真实 VisDrone 样例显示，本配方的框内保护与框外渐变按预期
发生，处理后的整图仍与原图相近；三幅图的平均绝对像素变化
约 3.78、5.22、6.11/255。视觉效果不能代替 AP，也不等同
Mosaic 训练批次的分布。参见
`VISDRONE_ORACLE_960_QUALITATIVE_AUDIT_2026-09-23.md`。

计算成本不小：同在 epoch29 时，候选累计 CSV 时间 1132.33 秒，
标准960为 371.678 秒，观察值约 3.05 倍；这不能直接归因到
某个组件。epoch85 同口径累计时间为 3611.98 对 1077.66 秒，
约 3.35 倍；这是训练迄今的实测开销，不是最终吞吐或纯滤波成本。
静态审计发现 p=.5 实现会先渲染全批，再丢弃未选中
一半的处理结果。一个**未接入正式训练**的 selected-only 版本在
本机和远端 CPU 单元测试均通过；四张真实 VisDrone 图的单次
CPU 输出逐像素相同，耗时 1.883→0.854 秒。另一个未接入的
局部有界强度图算法在三张真实图上使**建图组件**快约 8–13 倍、
最大强度差 <1e-4。两者均未证明整个 4 GPU 训练加速、DDP
兼容或 AP 不变，不能热修改正在运行的实验。参见
`SELECTED_ONLY_ORACLE_RENDER_NOTE_2026-09-23.md` 与
`VISDRONE_REAL_TARGET_MAP_COST_AUDIT_2026-09-23.md`。

## 创新性边界与下一步

现有 IA-YOLO、DENet、IAT 说明检测驱动的轻量前端并非新概念；
CVPR 2025 SET 已研究在训练期抑制小目标检测的背景高频噪声；
Scale-Aware AutoAug 也使用高斯空间软过渡，并报告完全移除
上下文会伤害小目标。因而“保护目标、平滑背景、YOLO 提点”
不是足够的论文主张。文献与具体限度记录在
`DESKTOP_LITERATURE_REVIEW_2026-09-23.md` 和
`DESKTOP_LITERATURE_ADDENDUM_2026-09-23.md`。

先等已注册的正式候选结束。若它在强960基线上没有稳定 AP
提升，应停止反复搜索模糊强度，转向已测量的尺度、定位、
置信度排序或上下文依赖问题。若单种子有收益，也只能算筛选
信号，需要同设置第二种子、健康硬件复现、完整耗时和外部
数据/模型泛化；后续如果做可部署学习式前端，必须单独验证
推理时无 GT、端到端延迟和相对简单增强的增益。
