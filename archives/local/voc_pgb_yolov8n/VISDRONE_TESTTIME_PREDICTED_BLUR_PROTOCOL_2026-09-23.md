# VisDrone YOLOv8n/960 仅推理阶段背景模糊：预定对照

时间：2026-09-23 20:05 CST。用户要求固定已训练原图基线，测试轻/中/重度推理背景模糊。这不是新训练，不修改模型权重、标注或原图。

## 方法边界

- 使用已完成的标准 YOLOv8n scratch、seed2027、125 epoch、960 输入 `best.pt`，在**同一官方来源 val 548 图、内部 YOLO 转换标签**上评估。此内部指标不等同 VisDrone 官方挑战 AP；val 已用于先前研究，不充当未碰过的最终测试集。
- 四个条件：原图；轻度 `sigma=3`；中度 `sigma=8`；重度 `sigma=16`（单位为完成 LetterBox 后的检测器输入像素）。四组均使用同一冻结权重、`imgsz=960`、`conf=.001`、NMS IoU `.7`、`max_det=1000`、FP32、不启用 TTA；本轮单 GPU 验证，统一 batch 大小。
- 对模糊组三组，先用原图运行**同一检测器的第一遍**，取 `conf≥.05`、NMS `.7` 的预测框。每框四周外扩该框宽/高的10%，且至少8输入像素，形成完全保留原图的保护区；边界以高斯 `sigma=8` 羽化。保护区以外，对原图分别用3/8/16像素高斯滤波替换。然后第二遍检测并计分。处理图像时完全不读取真值框；真值只由验证器用于计算 AP。
- 保留每组 mAP50、mAP50–95、10类 AP、第一遍平均框数、无框图数、受保护面积占比、原图平均像素变化和完整推理耗时。若模糊组优于原图，还需与**相近算力的常规两遍/多尺度推理**比较，不能只把第二遍成本藏起来。
- 预期风险：第一遍漏检的小目标无法受到保护；背景上下文缺失可能伤害定位与分类。即便三组中某组为正，本数据已被多次查看，不能当作论文终验结论，需要新留出集/其他数据和独立复现。
