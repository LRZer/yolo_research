# YOLO26 双头协同：无更新因果探针审计

日期：2026-09-18  
状态：训练划分、固定 checkpoint、无优化器更新；用于设计实验，不作为精度结果。

## 1. 为什么先做探针

D2（质量门控 O2M→O2O 分类 KL）在固定第 50 轮比 B50 高 0.00308 mAP50-95，但旧实现对筛选后的候选重新归一化，不能区分“选得更准”和“实际施加了更强梯度”。此外，训练器对全模型做 `max_norm=10` 的全局梯度裁剪，头部 KD 仍可能通过裁剪系数间接改变共享参数更新。

本审计回答三件事：

1. D2 的直接梯度究竟流向哪里；
2. D1 与 D2 的梯度量级是否匹配，以及全局裁剪是否形成间接耦合；
3. 分任务双向路由（TQGB）在训练数据上是否有足够覆盖，值得进入实现。

## 2. 梯度隔离回归测试

在真实 YOLO26n 前向上单独反传 KD 项：

| 参数组 | 最大 KD 梯度 |
|---|---:|
| Backbone / shared trunk | 0 |
| O2M head | 0 |
| O2O box head | 0 |
| O2O cls head | 9.52e-06 |

同时，`gain=0` 的官方基础损失严格等价；CUDA 重复归约产生的全模型基础梯度相对 L2 误差为 0.00106，处于既定容差内。结论是：KD 的直接梯度只进入 O2O 分类头，但这不等价于共享参数的最终优化轨迹不变，因为训练器随后做全模型裁剪。

## 3. 梯度量级与全局裁剪探针

协议：B50 的固定 checkpoint；VOC train 中固定 1024 张图、16 batches；batch 64；BF16；无 optimizer step；对 D1 无门控和 D2 质量门控都使用 gain=0.5。

所有被测 batch 的 base 与 combined 梯度范数都超过 10，裁剪触发率均为 100%。D2 只保留 14.9%–23.3% 候选，KD 梯度范数却比 D1 大 32%–53%；原因是旧 active-count reduction 将稀疏候选重新归一化为满强度。经全局裁剪后，D2 使共享更新相对纯 base 缩小约 0.64%–1.56%。这足以构成混杂，但量级不大，不能单独解释 D2 的全部结果。

训练数据固定批次给出的强度匹配估计为 `0.5 × D1_norm / D2_norm ≈ 0.33–0.34`。因此预注册 D2-GM 使用 gain=1/3，其余条件与 D2 完全相同。

反向路由远高于 1% 的预注册 go/no-go 下限，且约一半位置的分类/定位赢家不同。结论是 TQGB 具有真实覆盖，不是形式上存在但几乎不触发的模块。不过其实现和消融更复杂，先完成强度匹配与状态控制的低成本因果实验，再决定是否投入完整训练。

## 5. 由探针导出的实验队列

1. **D2-GM**：质量门控保持不变，gain 从 0.5 改为 1/3，检验 D2 是否在梯度量级匹配后仍优于 B50/D1。
2. **S-QGAT**：使用上一完整训练 epoch 的 `teacher_better` 全局比例，按训练统计自动衰减下一 epoch 的 KD；不读取 test 指标控制训练。
3. **Common reduction control**：分母改为所有 common same-GT 正样本，让候选覆盖自然控制总强度，用于区分 active-count 归一化效应。
4. 只有前述简单因果矩阵不足或 TQGB 信号明显更强时，才训练逐任务双向版本，并要求 forward-only、reverse-only、no-bridge 消融齐全。

## 6. 证据边界

- 这些探针全部使用训练数据，无模型更新，不构成 test 泄漏。
- 当前服务器有已确认的不可纠正内存错误；所有结果均为 faulty-host exploratory。
- VOC 单数据集、单 seed 的窄幅差异不能成为“可发表提升”结论。最终候选仍需配对多 seed、150 epochs、健康硬件复现，并扩展至 COCO2017。

原始数据位于 `diagnostics/kd_gradient_probe_b50_e50/` 与 `diagnostics/tqgb_probe_b50_e50_train/`。
