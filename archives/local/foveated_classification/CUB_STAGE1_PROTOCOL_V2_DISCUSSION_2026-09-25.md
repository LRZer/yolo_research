# CUB 中央凹分类第一阶段：实验协议 V2（讨论稿，未实施）

日期：2026-09-25。本文记录此前五项讨论后的建议；**没有启动数据处理、训练、评估或 GPU 作业**。用户随后提出原生像素补边至 500×500；本文件的 448 输入和像素尺度设定已由 `CUB_STAGE1_PROTOCOL_V3_NATIVE500_DISCUSSION_2026-09-25.md` 取代。本文件只作方案演变记录。

## 1. 问题与两种不同的操作

本阶段只问：**已知鸟的位置，保持鸟及近邻清晰、削弱远处高频背景，ResNet50 分类会怎样变化？** 真值框驱动的输入属于 Oracle 实验；它不证明无需框即可部署，也不产生实际 CNN FLOPs 节约。

优先做完整框保护：框每侧按本身宽/高外扩 10%，鸟及近邻保持原像素，框外渐进模糊。这回答“鸟外背景细节是否必要”。固定半径、仅以框中心为注视点的径向 fovea 留作后续不同问题，因为它可能模糊较长的翼和尾；不能混为一组。

## 2. 官方划分与测试集使用

- 官方 train 5,994 张全部训练，官方 test 5,794 张每轮评估；**不再从 train 抽 dev**。200 类头。所有组共用官方清单、类别映射、坐标变换和评估代码。
- 官方 test 每轮被观察后，实质上是“被反复监测的测试集”，不再是从未看过的盲测集。它的曲线可用于描述收敛，但不得再称最终无偏外部泛化估计。不得依据这条曲线选择模糊半径、σ、学习率、epoch 数或仅挑某一组的最好权重后宣称获益。
- 训练前冻结协议。每组的**固定第 200 轮 last 权重**为主结果；test-top1 最佳 epoch 及其权重仅描述，不作为主要排序依据。后续要有独立确认，使用预先锁定方案在另一个合适的数据集或新保留样本上评估；Oxford-IIIT Pet 不应直接声称可照搬 CUB 的 200 类与鸟框条件。
- 原始 CUB 数据不改。既有 30 张框越界的情况仅在变换的派生坐标中裁边；灰度 JPG 转 3 通道；掩膜只做后验鸟体保护诊断，不作为分类模型输入。

## 3. 模型、分辨率与处理顺序

- 分类器：torchvision ResNet50，200 类头，**随机初始化、不用 ImageNet 权重**。所有对照共享同一个主干和训练策略。CUB 官方提示其图像与 ImageNet 有重叠；从零训练可避免这一预训练来源疑虑，但仅约 6,000 张训练图像使过拟合风险显著，需要诚实报告。
- 建议以 **448×448** 为主输入；按比例缩放原图使长边到 448，短边居中填充，**不裁鸟、不强拉伸为正方形**。例如原 500×333 → 有效图约 448×298，再填充到 448×448。模糊只作用于有效图像区域，填充不参与距离或模糊剂量统计；框随几何变换精确对齐。归一化在变换后。
- 对典型长边 500 的图像，224/384/448 分别保留约 45%/77%/90% 的线性采样尺度；有效图像面积约为原图的 20%/59%/80%（按等比例重采样估算，不等于信息保留百分比）。224 可作为低分辨率敏感性实验，但不作为研究细粒度鸟体纹理的唯一主输入。
- 448 的密集 ResNet50 计算约为 224 的 4 倍；这只是按输入面积估计，真实 FLOPs、显存和端到端耗时以后再实测。若实现时资源预检表明 448 不可安全运行，则在**看到任何测试准确率前**统一改为 384，所有对照与种子同改并记录，不允许只对某组更换分辨率。
- 主变换在共同几何/颜色增强之后、归一化之前进行。尽量让匹配种子下每张图每轮的随机增强相同。训练与每轮测试分别使用各组自己的同类表示，避免“训练模糊/测试原图”的额外分布偏移。另可把交叉输入评估单列为诊断。

## 4. 模糊剂量与公平对照

在有效图像坐标中，令 P 为真值框每侧外扩 10% 后的保护区；P 内完全不改。对 P 外的距离 d，V2 的**待冻结起点**为：`q=clip(d/64,0,1)`，`s=3q²−2q³`，`σ(x,y)=8s(q)`（448 输入像素）。预先生成 σ∈{0,2,4,8} 的滤波图，在相邻尺度连续混合。这大致对应旧 224 草案中的 32 像素过渡和 σmax=4；数值是实验设定，不是视觉理论常数。若主输入改 384，过渡和 σ 应按 384/448 缩放并在任何模型运行前冻结。反射边界限制在有效图区域，保护区内部输出需与增强后原图逐像素相同。

| 组 | 表示 | 解释 |
|---|---|---|
| A Original | 原图 | 同训练预算主对照。 |
| B Global Blur | 有效区域统一 σ=8 | 鸟细节被破坏的诊断，不是信息量严格匹配的主对照。 |
| C Context Removed | P 内清晰，P 外逐渐混合到训练集 RGB 均值 | 判断低频上下文是否有用；和 D 的频谱剂量不完全等价。 |
| D Box-protected Gradual | P 内清晰，P 外渐变模糊 | 主研究组。 |

先以完全相同预算配对 A/D，再补 B/C 的解释性对照；不能只比较“448 的 D”和“224 的 A”。如果后续需要 224 输入的分辨率交互检查，A/D 都应分别从零在 224 下训练，不把 448 权重直接降分辨率测试当成同等训练比较。处理前先用**训练集几何**审计实际模糊覆盖率、框/鸟掩膜保护率和可视化；若剂量几乎为零，参数必须在看测试结果前修订，而不能通过测试集挑参数。

## 5. 轮数、优化与复现

- 建议固定 **200 epoch**，从零训练的 A/B/C/D 均相同。5994 张、全局有效 batch64 时每轮约 94 个优化 step，总计约 18,800 step。每轮评估 5,794 张 test，相当于每组约 116 万次测试图像前向，实际墙钟耗时待以后单轮试运行测定。
- 暂沿用共同起点：SGD momentum 0.9、weight decay 5e-4、global batch64、初始 LR 0.025、5 epoch warmup + cosine、交叉熵。输入变大后如每卡 batch 不足，用梯度累积保持有效 batch；必须保持所有组一致，并明确 BN 实际每卡 batch。水平翻转与温和颜色增强共用，不做可能裁掉鸟的随机裁剪。
- 200 并非已知最优。大模型 + 小型细粒度数据可能过拟合；不能通过反复看 test 曲线决定只给有利的一组早停或加训。如果 200 轮训练目标仍明显未收敛，只能预先定义**全部组统一扩至同一轮数**的第二版协议，或将 200 轮作为本轮完整结果后再做新的明确标记实验。不得覆盖本轮结果。
- 首批 A/D 建议至少两个配对种子 2027、2005；B/C 可以先一组种子做诊断，如结论依赖它们再补种子。匹配初始权重、样本顺序、增强随机流、epoch/batch 预算和推理流程。训练前测 SHA/参数量/输入相等性；保存每轮曲线、last 和仅供描述的 best、配置与原始评估表。

## 6. 判读、局限与下一步

主指标：第 200 轮官方 test 的 Top-1；次指标：Top-5、200 类平均及逐类准确率、交叉熵、A/D 逐图对错翻转、按目标框面积/偏心/可见部位分层的表现、模糊面积与强度、训练/推理耗时。报告配对图像差与多种子变异；不把同一 test 的 200 次重复测量当成 200 个独立验证集。可预登记 D−A 的容忍下降边界，例如 −1 个百分点；在重复看 test 的前提下，统计区间只描述固定协议结果，不能声称完全无选择偏差。

若 D≈A，只能说在**真值框已知且448输入、当前剂量**下，外围高频可降低而分类几乎不变；模糊并未节省 ResNet50 FLOPs。D>C 才支持低频上下文在当前设计中可能有价值。若 D 显著差于 A，先审计变换/保护区/数据流水线、细粒度部位和小框，再决定当前表示 no-go。若 D>A，也不能排除因 D 独享测试时的真值位置先验。真正的效率问题需第二阶段对实际非均匀采样与**等计算**的普通降分辨率、裁剪模型比较；自主注视与多次注视更后做。
