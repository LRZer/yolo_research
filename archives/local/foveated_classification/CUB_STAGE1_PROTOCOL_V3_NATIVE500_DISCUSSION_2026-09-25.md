# CUB 分类中央凹第一阶段 V3：原生像素 500×500（详细讨论稿，未实施）

日期：2026-09-25。状态：**只规划，不实施**。本稿取代 V2 的 448 缩放策略；ResNet50 从零训练、官方 train 训练/官方 test 每轮评估、同预算对照、200 epoch 仍为建议。原始数据不改；未创建变换代码、模型、训练、评估或 GPU 作业。

## 1. 为什么可以用 500×500；真正的代价是什么

已验收 CUB 图片宽 121–500、高 120–500。对每张已解码图按原生 W×H 像素处理，再居中填充到 500×500。常见的 500×333 加上下约 83/84 像素填充；500×500 不填。小于 500 的图片**不放大**，不存在“把 121×120 的小图变成高清”的错觉。保留原生采样尺度，但 500×500 画布中有些像素是填充，不等于信息量增加。JPEG 解码、L→RGB、浮点归一化仍是必要操作；训练时水平翻转/颜色变换也会改变像素，但不做几何缩放。

统一画布使普通 batch 可堆叠。ResNet50 的自适应全局平均池化并不要求输入边长必须为 224 或 32 的倍数，因此 500 可输入。其内部步长下采样依旧会损失细节；500 只避免**输入前**的缩小。按公开 224 输入 4.09 GFLOPs 粗按面积外推，500 约 20.4 GFLOPs/图，是 224 的约 5 倍、448 的约 1.25 倍；不含模糊/填充/解码等预处理，实际速度/显存须实测。小图填充比例很高，ResNet50 仍对整幅500画布计算；按原生长边或框面积分层报告，不能把所有图都当作500原生采样。

建议填充值取**官方训练集有效 RGB 像素计算出的三通道均值 μ**；归一化用同一训练集均值/标准差，故填充通常映射近零。计算统计量时排除填充，不从 test 估计。所有组同一填充、位置与归一化；真实框及鸟掩膜只在原生 W×H 内操作，再统一加填充偏移。填充本身会有边界信号，但各组相同。512×512 不必为了整除32而额外填充，是否因硬件算法更快不能预设。

## 2. 这里的“模糊模块”到底是什么

阶段一**没有可学习模糊网络**。输入变换 T 是一段预先固定的确定性处理：读原图/框 → 生成处理图 → ResNet50 分类。只有 ResNet50 的参数被交叉熵优化，模糊参数（保护圈、σ、过渡宽度）不被训练。它属于 **GT 框驱动的 Oracle**：训练图用训练标注框，官方 test 每轮评估也用 test 图的标注框生成处理图。ResNet50 本身只收到处理后的三通道图，不另收框坐标或分割掩膜，但图像改动隐含了真实目标位置。未知新图没有 GT 框，不能照此直接部署；后续才研究预测注视点/框。

对于某组，**训练与每轮测试评估均用该组规定的同一种表示**。A 永远原图；B 训练和测试均整图模糊；C 均外围替换；D 均框外渐变模糊。训练模糊而测试原图，或训练原图而测试模糊，是另一项分布偏移诊断，不与匹配训练的主表混用。test 无随机增强，但仍按该组的确定性处理变换。每轮看官方 test 后，它不再是完全未接触的盲测；不依据其曲线调 σ、保护圈、轮数或只选最优测试轮作主结论，主指标用预定第200轮。

## 3. 共用的加载/坐标管线

1. 官方 ID→图像/类别/训练测试划分/原始 `(x,y,w,h)` 真值框严格匹配。RGB JPG 保持RGB；8张灰度 JPG 复制为3通道；30个越界原始框只在派生坐标中裁到 `[0,W]×[0,H]`，不改原始文件。像素中心、框半开边界及可视化覆层先做单测，避免1像素错位。
2. 训练期先在原生 W×H 上做共同水平翻转、温和颜色变换（不缩放、不随机裁鸟）；翻转后同步更新框。相同种子和图像ID×epoch应能产生匹配随机增强。test 无随机增强。
3. 在**尚未填充的有效 W×H 区域**上完成 A/B/C/D 变换，所有卷积只对有效图像做反射边界处理；填充不能卷进滤波。然后居中填充至500×500，最后归一化并送同一 ResNet50。若某窄小图在反射边界/卷积核尺寸下不满足实现条件，必须有安全、明确的替代边界规则并留痕。
4. 始终保留有效像素 mask、图像原尺寸、填充偏移和框坐标用于剂量/保护率审计；mask 与 GT 框**不作为**分类网络通道。独立分割包仅用于事后测真实鸟体被处理比例，不能用于主变换或未知图推理。

## 4. A、B、C、D 四组的确切输入

令 I 为完成共同增强后的原生有效 RGB 图；μ 为训练集 RGB 均值；P 为下节定义的扩大鸟框；s(p)∈[0,1] 是离 P 越远越接近1的平滑过渡。

| 组 | 有效图像输出 | 实际含义 |
|---|---|---|
| A Original | `I_A(p)=I(p)` | 全部原生图像细节，主基线。 |
| B Global Blur | `I_B(p)=G_{σmax}(I)(p)` | 鸟和背景**都**被高斯模糊；检查鸟体细节整体丢失的代价。不是与D等模糊面积对照。 |
| C Context Removed | `I_C(p)=[1-s(p)]I(p)+s(p)μ` | P 内原样，过渡区逐渐淡出，远背景变成均一颜色；“移除”指像素信息替换，**不是裁切图像、缩放鸟或减少CNN计算**。兼保留平滑边界，不在框边形成突变。 |
| D Box-protected Gradual | `I_D(p)=连续混合的G_{σ(p)}(I)(p)`，且P内强制 `I_D=I` | 鸟框及邻近原样，框外越远模糊越强；保留远背景的粗颜色/结构。 |

所有组都输出相同原生 W×H、再同样填充到500×500。C的均值替换会同时丢掉细纹、粗结构和远背景颜色差异；D主要降低高频，仍保留低频轮廓，故 **D>C 只能在控制其他差异后支持“低频上下文可能有用”**，不能简单归因为“模糊比删除好”。B是诊断而非信息量严格匹配对照。额外的硬切背景（P外立刻常数）和目标裁出再放大是不同操作，若做应单列。

## 5. D 的几何与数值实现（待训练前冻结）

原始有效框先裁边得到 `[x1,x2]×[y1,y2]`。令框宽 `w=x2−x1`、高 `h=y2−y1`，保护区 P 为框四边各外扩 `0.1w/0.1h` 后再裁到有效 W×H。任意有效像素中心 `p=(u,v)` 到 P 的距离：

`dx=max(x1P−u, 0, u−x2P)`，`dy=max(y1P−v, 0, v−y2P)`，`d(p)=sqrt(dx²+dy²)`。

P 内距离为0。为了原生图大小不一时保持相似的**相对**过渡，定义 `L=max(W,H)`、`a=L/500`；V3讨论起点是 `T=70a` 像素、`σmax=8a` 像素。`q=clip(d/T,0,1)`，`s(q)=3q²−2q³`，`σ(p)=σmax·s(q)`。500 长边图 T=70、最远 σ=8；较小原生图按长边同比缩放。参数只是约定的第一试验剂量，不是已验证最佳值。为避免把缩小图当高清图，不对 I 做尺寸变化。

先对有效原生图生成四张图：`G_0(I)=I`、`G_{2a}(I)`、`G_{4a}(I)`、`G_{8a}(I)`（高斯标准差以**原生像素**为单位）。若某位置 σ 落在相邻两级 `σ_j,σ_{j+1}` 之间，令 `α=(σ−σ_j)/(σ_{j+1}−σ_j)`，输出 `(1−α)G_{σ_j}(I)+αG_{σ_{j+1}}(I)`。P 内最终覆盖写回原像素，防止浮点或插值误差误伤目标。这是多张全局高斯图的**空间连续混合近似**，不是每位置真正使用不同核的精确动态高斯，也不是物理镜头景深。模糊卷积在 P 边可能把鸟的颜色扩散进框外，形成轻微晕圈；需可视化和量化，不能仅靠 P 内逐像素一致就宣称完全无边界影响。

示例：500×333、裁后框100×100时，P每侧外扩10像素；P内 σ=0；刚出P时 σ缓慢增加；距P ≥70像素处 σ=8。若框占了大片图，实际上可模糊面积较小，必须报告每图有效面积的清晰率、`σ≥4a`比例和平均 σ，按框面积分层。C使用**同一 P、T、s**作为淡出权重，以避免两组因保护范围不同而不可解释。

## 6. 训练、评估与可解释性

- 从零初始化 ResNet50 200类头；建议固定200 epoch，同一有效batch/优化器/学习率/公共增强及训练图顺序。500输入显存与墙钟将高于448；实际每卡 microbatch 需预检。梯度累积只保持优化有效batch，不能自动修复 BatchNorm 每卡 microbatch 太小的问题；若硬件不能安全支持既定方案，要在**看任何 test 准确率前**统一修订所有组。
- 先 A/D 两种子配对，再 B/C解释性对照。Top-1、Top-5、每类准确率、按框面积/原始分辨率/鸟体部位分层、A↔D逐图对错翻转、交叉熵、训练和完整预处理+网络推理时间，另报背景处理率及分割掩膜鸟体保护率。第200轮last为主；best-test仅描述。
- 如果 D≈A：只支持**已知真值框**时某种程度的外围高频可去，不代表无需上下文/自动找目标/更快；D>A还需对照同等清晰面积的随机保护区，避免把“GT泄露目标位置”的帮助误写成“模糊本身”帮助。C、B亦提供机制解释但不是完全信息量匹配。
- 若全部500组总成本太高，不能临时只把 D 改回448；可在开始正式比较前整体重定协议，或预先安排少量相同分辨率的A/D敏感性实验。500原生方案更直接测外围细节，但仍是密集卷积，**不会因模糊或均值填充减少 ResNet50 FLOPs**。

## 7. 尚待冻结的实现细节

优先核查：500输入单卡显存、可接受每卡batch和Epoch时间；训练集RGB均值/方差；原始框坐标约定及30异常框；滤波边界、核截断及P内精确保护；在小原生图上σ缩放是否引起剂量不足；按训练集几何计算出的实际背景覆盖率。依据**训练集几何/预处理可视化**决定是否修订 T/σ，再冻结；不在官方 test 上反复搜索。用户正式要求执行前，此稿保持讨论状态。
