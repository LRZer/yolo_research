# 图像分类中的目标保护与中央凹表示：第一阶段讨论方案

日期：2026-09-24。状态：**研究设计草案，尚未启动训练或推理**。本文写作时用户要求先思考、当时尚未下载数据；同日稍后用户授权下载，CUB 两份官方包的完成状态与审计见 `CUB_OFFICIAL_DOWNLOAD_AND_AUDIT_2026-09-24.md`。本文的参数与门槛仍未通过分类实验验证。旧VOC/VisDrone检测实验结果保留，本方案建立新的分类问题。

## 1. 建议研究问题与证据边界

先回答：对于CUB单个主要鸟类实例的分类，当目标及邻近区域细节保持时，降低其余区域的高频细节是否可以维持准确率？随后再问：清晰区域缩成以目标中心为中心的有限圆形视野后，准确率如何随半径、可见部位保留率和外围处理强度变化？这两问仍属于第一阶段的表示实验。

已知GT框中心不等于已完整保护目标。鸟的头、翅膀和尾巴可能远离框中心；固定R=32或48的圆会模糊目标自身。故把**完整框保护的背景实验**与**固定注视点的径向中央凹实验**分别命名、分别解释，不将后者的负结果直接归为背景无用。

所有依赖GT中心、大小或框的实验均为已知目标位置条件下的Oracle表示研究；可支持受该先验条件约束的分类结论，不能作为无需标注的部署分类准确率。GT框的形状、大小和位置本身也可能向模型透露类别相关信息；所有处理都应注明使用了哪些先验。

## 2. 一手来源核查及研究定位

- [Pramod、Katti、Arun：Human peripheral blur is optimal for object recognition，Vision Research，2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC7614542/) 已在有框的ImageNet子集上，以框中心为注视位置、构造不同外围模糊程度，分别从随机初始化训练分类网络，并报告小幅收益。这与本设想直接相关，应作为第一篇方法参考。本文只据其支持可行性和既有研究定位，不将收益大小外推到CUB或ResNet18。
- [FoveaTer（作者预印本，2021）](https://arxiv.org/abs/2105.14173) 已讨论中央凹表示、Transformer分类及注视机制；不能把以后加入Transformer或注视选择本身视为新贡献。
- [Foveated Retinotopy Improves Classification and Localization in Convolutional Neural Networks（作者预印本，2024）](https://arxiv.org/abs/2402.15480) 是非均匀空间表示与CNN分类的进一步相关工作。本轮仅核对其题名和研究范围，没有声称已逐项复现。
- [Recurrent Models of Visual Attention，NeurIPS 2014](https://proceedings.neurips.cc/paper_files/paper/2014/hash/3e456b31302cf8210edd4029292a40ad-Abstract.html) 已研究依次选择局部高分辨率区域完成任务；主动多注视应放到更后阶段。

第一阶段定位为已有思想在细粒度分类中的可复验机制研究。候选贡献只能在证据出现后收束，例如对鸟类关键部位保护、目标尺度和背景细节预算关系的有限适配。更换数据集、backbone或模糊核本身不足以证明创新。

## 3. 数据与初始化

首选[CUB-200-2011官方数据](https://www.vision.caltech.edu/datasets/cub_200_2011/)：200类、11,788张，逐图有目标框、15个部位位置等标注，适于同时审计框覆盖和可见部位受损。按标准官方划分使用训练5,994张、测试5,794张；实施时以发布文件重新核对计数和完整性。本次未下载或验收。

建议从官方训练中每类固定抽5张作开发集，共1,000张，余4,994张作开发训练；拆分种子2027，保存文件名与SHA。所有变体及其原图共用划分。参数和训练预算只在开发集决定；冻结后若要用全5,994张重训，所有最终组按同一规则重训，再一次性评价官方test。若直接保留4,994张训练方案，正式报告亦须如实标明，不能混用两种训练样本数。

沿用用户此前从零训练偏好：ResNet18随机初始化、200类分类头、224×224输入。CUB每类训练样本不多，从零训练可能受泛化限制；必须先检查原图基线收敛、训练/开发差距、每类准确率，避免把一个很弱的分类器对模糊不敏感当作高分辨率冗余的证据。若以后增加预训练对照，须独立标记初始化来源、各组一致。CUB官网明确提示与ImageNet存在图像重叠，所以预训练条件还需披露该限制。

第二数据集暂放到CUB机制确认之后。[Oxford-IIIT Pet官网](https://www.robots.ox.ac.uk/~vgg/data/pets/)说明它有37类，框标注针对**头部**，另有全身前景trimap。若研究整只动物，应固定从trimap导出全身包围框，或明确只研究头部注视；不能直接把头部框当全身框。实际发布包的框、trimap和各划分覆盖率须届时核验。

## 4. 输入处理的共同约束

第一轮把原图等比例缩放到224画布并填充，保留完整视野，记录有效图像区域；框与部位坐标做相同变换。填充不计入高清/背景面积。使用同一归一化、翻转和轻量颜色增强；增强后再生成对应处理图。第一轮暂不采用会裁掉主体的RandomResizedCrop、MixUp、CutMix。若机制成立，后续须在常见更强训练配方下复验，不能只比较弱基线。

所有成对运行共享初始化、数据顺序和增强随机数。随机注视使用单独随机数流，避免它改变其它数据增强。GT只用于已声明的Oracle变换；分类器仍只接收三通道图像，不额外输入类别、框或部位坐标。视觉QA须按类别/目标尺寸/偏心位置分层预选，不能只挑好看的例子。

## 5. 第一阶段A：先检验框外高频细节，初批四组

| 组 | 目标/邻域 | 其余区域 | 主要问题 |
|---|---|---|---|
| A Original | 原样 | 原样 | 相同配方的原图基线 |
| B Global Blur | 模糊 | 模糊 | 模糊全部区域的诊断对照，不能称等信息预算对照 |
| C Context Removed | 原位置、原尺度保留 | 相同画布上用固定中性色替代，并采用预定过渡边界 | 去掉目标外上下文后如何 |
| D Box-protected Gradual | 完整框及固定邻域保留 | 距保护区越远处理越强 | 保留粗背景能否维持准确率 |

建议初始保护区P为GT框每侧外扩10%，到画布边缘裁剪；sigma_max=4、过渡宽T=32均以处理后的224输入像素计。这是单一预定起点，不是优选结果。令d_P(x,y)为到保护区的欧氏距离（区内为0），q=clip(d_P/T,0,1)，h(q)=3q²−2q³：

sigma(x,y)=sigma_max · h(q).

实际实现可用0/1/2/4的高斯滤波图作相邻尺度连续混合，称空间变低通近似，不能称精确逐像素动态高斯核。P内应逐像素等于原图。C尽量复用D中原图分量的空间权重，把其余滤波分量换成同一训练统计得到的中性色，以减小边缘处理差别；这仍是人工干预，D胜C只支持该条件下保留背景低频有帮助，不能证明自然背景普遍有用。

**不要把Crop+Resize作为C。**真正的裁框再放大到224会增加目标尺度、改变位置并删掉上下文，无法单独解释背景作用。它可以在核心结果后作为单独强对照E Crop-Resize报告，但不用于直接归因H2。

若D出现可复现的保留精度区间，再加入F Hard Background Blur：同一P内原图、外面固定sigma_max，和D比较连续过渡是否有必要。Hard与Gradual的平均模糊剂量不同，须记录真实处理面积与强度；如果要把差别归因于过渡形状，另加按训练图几何/滤波权重匹配剂量的对照，不能只凭D>F下结论。

## 6. 训练和冻结模型的测试分别回答不同问题

先训练A原图基线，并在开发集对固定变换做冻结权重诊断。该诊断适于检查流程和输入分布变化，**不能因A模型不适应模糊就否定模糊表示**。正式比较应独立从相同初始化训练A/B/C/D，让各模型在本组表示上训练及评估。

至少保留A与D的2×2交叉评价：

| 训练表示 | 测试原图 | 测试D表示 |
|---|---|---|
| 原图A | 标准基线 | 已训练原图网络的处理鲁棒性 |
| D表示 | 迁移回原图的能力 | 学会适应D表示后的分类能力 |

若A→D下降而D→D恢复，分布不匹配是因素；若匹配训练后仍下降，才有更强的表示损失证据。D→D接近A→A仍仅说明这个模型/数据/监督条件下可保留性能，不是信息论上的无损证明。

共同训练起点建议：ResNet18 scratch、batch64、交叉熵，SGD(momentum0.9)、weight decay5e−4，初始学习率0.025、5轮warmup加cosine，总200轮；具体预算由原图开发试验核实收敛后对所有组冻结。200轮仅为候选配置，不能从我们YOLO的125轮直接推导。最后一轮为固定预算主结果，各自dev最优权重仅作次要结果；如采用相同早停/最优checkpoint协议，需要事先固定并报告实际预算。

探索先seed2027跑四组；主要对比A/C/D再用2005和42确认，原2027可复用，开发阶段共10次完整训练（4+3×2），不含后续半径试验或可选的全5,994张重训。若B产生核心结论，再补其余两种子，不能以单种子B写稳健结论。数据规模/时延本轮未实测，不承诺完成小时数。没有证据支持时不先做25点全网格、多个backbone和多注视训练。

## 7. 第一阶段B：真正的中心注视与半径曲线

框保护回答目标外背景问题，径向中央凹还会改变目标内部细节。后者单列，仍采用同一ResNet18和224画布：r为到注视点距离，q=clip((r−R)/T,0,1)，sigma=sigma_max h(q)。初始R48、T32、sigma_max4；目标GT中心、图像中心、固定随机中心是三种不同注视来源。

中心随机对照应与GT中心采用同一半径、滤波曲线和训练预算，固定每图随机种子；主实验每图一张随机视图，不能多视图概率平均后冒充单次推理。额外多随机中心只用于估计随机性，报告平均正确率而非集成。GT中心和随机中心靠边会改变实际清晰面积，需记录并按面积/偏心分层；面积明显失配时不能把所有差异解释成对准目标的价值。图像中心是必需的廉价对照，因为CUB/Pet图像可能有拍摄居中偏好。

先按R=32/48/64固定sigma4和sigma=2/4/8固定R48进行两个一维探索，共5个不同配置。冻结A的dev诊断只作敏感性曲线；完整匹配训练只选择事先锁定的代表配置，不能把未重训的曲线称各表示最优能力。若仍需原提议16/32/48/64/96和1/2/4/8/16的大范围扫描，优先作无训练的dev几何/损伤审计，然后预定至多两点重训确认。

利用15部位的**可见性标记**统计头、喙、眼、翅/尾等点落在清晰区或过渡区的比例，以及框内平均处理量；部位只用于事后解释，不用于选择最佳注视点。若小R下降且关键部位被处理，这是目标证据减少，不能说外围背景必需。若框保护D有效而径向版本无效，可能值得研究目标形状/部位感知适配，但这仅是后续待检验假设。

## 8. 指标、非劣判据与停止条件

第一阶段核心输出：Top1、macro每类Top1、Top5、逐类准确率、原正确→处理错误/原错误→处理正确的配对计数；附训练/开发曲线，按框面积、位置、可见部位受损、处理面积分层。后者是诊断，不在测试集选择最佳子群报告总体成功。

不把“差异不显著”直接等同于“效果相同”。建议预先约定可接受Top1绝对下降delta=1.0个百分点，主要比较D匹配训练和A匹配训练。报告3个种子的各自差值、均值/标准差；按同一图像配对、按类别分层bootstrap给出样本不确定性。只在预定单侧95%区间下界高于−delta时称满足这一非劣门槛；区间跨界就是证据不足。样本CI与跨seed变异分别报告，不能把3×N张预测当作3×N个独立测试样本。开发集仅1,000张，细小差异的检验力有限；正式判断在配置冻结的5,794张官方测试上完成。

同时应确实处理了有意义的有效背景区域。建议事先将“至少25%有效图像像素达到sigma≥sigma_max/2”的数据集平均比例作为初步操作性检查，并完整报告分布；25%仅是研究门槛草案，不是人类视觉理论常数。如果处理仅占几个百分点，即使精度不变也只支持很弱结论。高清面积、sigma图、像素差和高频能量代理均不等于真实信息量或采样点数。

“达到基线95%准确率”不宜单独作为成功标准。例如原图80%，95%相对保留只有76%，绝对下降4点、错误率从20%到24%（相对错误增加20%）。应采用预定绝对精度容忍度和完整精度—成本曲线。

决策表：

| 证据 | 允许的判断/下一步 |
|---|---|
| D非劣于A，背景处理面积足够 | 支持已知GT区域条件下背景高频存在可舍弃部分；进入径向/更少采样验证 |
| D高于同画布C，多seed方向一致 | 支持保留粗背景可能有用；检查边缘干预、部位和类别分层 |
| D与C相当 | 不能声称粗上下文必要；也许更简单的只看目标即可 |
| Crop-Resize最强 | 可能是放大目标更有效，单独研究尺度收益 |
| GT中心明显优于图像中心和面积可比的随机中心 | 已知目标位置有作用；尚未证明可自主定位 |
| 合理强度下D匹配训练仍稳定明显劣于A | 当前CUB/ResNet18条件不支持方案；先审计关键细节/基线，停止大网格和扩模型 |
| 只有近乎不处理或极大清晰区才非劣 | 不能据此预计显著计算节省 |
| 基线未收敛、随机种子波动大、CI跨门槛 | 结论不足，先解决可比性；不把“不显著”包装为等效 |

## 9. 后续阶段只留接口

多尺度模糊仍输入224×224、同一ResNet18，分类器FLOPs和参数不减少，端到端成本还增加滤波。第一阶段记录分类器与预处理耗时、FLOPs、参数，但主要横轴是外围细节处理程度/清晰面积，而非虚构的计算削减。

真正非均匀采样必须让网络实际处理更少像素/token：128²+64²+32²=21,504，为224²=50,176的约42.9%；这是三个张量的采样量例子，包含重叠且不等于40%的总FLOPs。如果又上采样回224、拼成原大小密集图，原CNN FLOPs仍不减；多分支、定位器、数据解码、融合都须进入总成本。同预算普通低分辨率分类和简单目标裁剪是必需对照。

只有表示及预算门槛通过后，才用低分辨率全局图学习注视点并完整计入定位成本；部署输入只允许图像，不能回退到GT。多次注视更后，停止阈值须在dev校准并验证误差—平均视图数，不能把高softmax分数直接等同于正确。ConvNeXt/ViT与Pet均在首轮机制清楚后作为复验。
