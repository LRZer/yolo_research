# CUB 中央凹分类：第一阶段可执行实验协议（仅规划）

日期：2026-09-25。状态：**旧版方案草案，未实施**。其中训练/开发/测试划分、ResNet18、224 输入和相关模糊像素参数已被用户 2026-09-25 的新决策覆盖；不要据此启动实验。新版讨论协议见 `CUB_STAGE1_PROTOCOL_V2_DISCUSSION_2026-09-25.md`。本文件仅保留方案演变记录。

## 0. 研究问题与不能越过的边界

主问题：**已知鸟所在区域时，降低鸟框以外的高频细节，能否在 CUB-200-2011 的分类中维持原图准确率？** 次问题：保留低频外围上下文是否优于完全去掉外围？这两问属于已知真实框的 Oracle 表示研究，并不证明模型能自己找到目标，也不证明节省了 CNN 的计算量。

必须区分两种问题：

1. **框保护背景实验（本轮主实验）**：完整鸟框加上下文圈保持清晰，只处理框外。可解释目标外背景细节的作用。
2. **径向中央凹实验（条件通过后再做）**：以框中心为注视点，固定半径内清晰；可能模糊鸟的翅、尾等部位。其失败不能直接说明背景有用。

2022 年的[原始外围模糊研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7614542/)已在目标框中心、图像金字塔和多个模糊剖面上研究过分类；本轮的分级高斯混合是更简单的**机制基线**，不是对人类视网膜或该论文算法的忠实复现。不能把思想本身称为新发明。

## 1. 数据划分：先冻结，再看模型结果

仅用官方训练部分 5,994 张构造开发阶段数据。按200个类别分别用固定种子2027和稳定排序抽 **5张/类为dev**，合计1,000张；余4,994张为train（194类各25张，6类各24张）。官方test 5,794张在架构、模糊参数、训练轮数和选择规则锁定前不得用于反馈调参。保存图像ID、相对路径、类别、官方划分、抽样种子和清单SHA-256；所有实验共用同一清单。

初批比较可使用这4,994/1,000划分。若通过开发阶段门槛，最终把选定的A/C/D组用**完整官方train 5,994张**、同一预定训练预算和种子重新从零训练，再对官方test做一次冻结评估；不得将4,994训练的test结果与5,994训练的模型混在同一主表。

图片与标签来自已验收的官方包。30张越界原始框仅在派生坐标变换时裁到有效像素范围，原始文件保持不变并保存异常ID；若裁完为空则停下调查。8张灰度JPG显式转RGB；2张`LA`掩膜仅作诊断时取亮度通道、检查alpha。掩膜有0/51/102/153/204/255六档，不能未经定义直接当硬二值。

## 2. 统一输入与处理顺序

统一输出224×224。原图按比例缩放使长边至224，用双三次插值/抗锯齿，短边居中填充；填充值和归一化均由**开发train的RGB统计量**一次性计算并固定。框、15部位点及可选掩膜使用相同的几何映射；掩膜几何重采样用最近邻，不得将其作为模型输入。有效图片区域与填充像素分开记录。

训练期公共增强：水平翻转概率0.5、亮度/对比度/饱和度各最多±10%，无垂直翻转；暂不使用RandomResizedCrop、Mosaic、MixUp或会剪掉鸟的随机裁剪。四组共享每个“图像ID×epoch×种子”的几何/颜色增强抽样，然后在增强后的RGB有效区域上应用各自表示，再归一化。验证/测试无随机增强。Gaussian滤波只在有效图片区域做反射边界扩展，避免填充色渗进图像。所有组使用完全相同的分类标签与200类头；真实框只控制已声明的Oracle图像变换，不作为额外网络通道/标签输入。

令P为**裁边后的真实框每侧外扩框宽/高的10%**。对有效像素位置z，d(z,P)为到P边缘的欧氏距离，P内为0。令 `q=clip(d/32,0,1)`，`s(q)=3q²−2q³`，目标模糊尺度 `σ(z)=4s(q)`（单位：224画布上的像素）。先生成σ=0/1/2/4的图像，再按σ(z)在相邻两级线性插值；P内输出必须与增强后的原图逐像素相等。此法是空间变化低通的离散近似，不是精确逐像素动态高斯，也不是在降低224×224 CNN FLOPs。参数10%、32、4均为预先选定的第一起点，不得看到test结果后暗改。

## 3. 主要对照组与解释权限

| 代号 | 输入处理 | 回答的问题 / 限制 |
|---|---|---|
| A Original | 保留完整原图 | 同训练预算标准分类基线。 |
| B Global Blur | 整个有效图像固定σ=4 | 鸟体细节也被破坏的诊断下界；不是等信息量对照。 |
| C Context Removed | P内原图；外部用与D相同的`s(q)`逐渐混合到训练集RGB均值 | 保留目标但移去远背景，测试粗上下文是否还有用；与D的频谱剂量不完全相等。 |
| D Box-protected Gradual | P内原图；框外按上述σ(z)渐增 | 主方法。与A比较背景高频是否可舍弃，与C比较保留低频背景的价值。 |

此外做一个**零模糊sham**程序对照：仍读取框并运行坐标流程，但输出须与A输入逐像素一致；不需要独立长训。不要把“裁框再放大到224”当C，它改变鸟的尺度；它只可在主要结论后单列为强参考。若D有希望，再补同P的硬切换模糊和随机/图像中心注视控制，并匹配清晰面积/处理剂量，避免把“已知目标位置”误当成模糊本身的增益。

## 4. 启动前质量门（到时才实施）

1. 在CPU上单测坐标、水平翻转、填充区域、灰度图、LA掩膜、30张越界框、空框报错、P内逐像素不变、随机数复现以及增强后框/点对齐。可视化样本按类别、框面积、偏心和30异常框预选，不靠主观挑好图；同时保存原图、A/B/C/D、σ图、GT框和掩膜叠加图。
2. 只使用开发train的几何信息检查处理剂量：报告有效像素中`σ≥2`的比例、完全清晰比例、`σ`分布。若全体平均仅极少像素被处理，则当前剂量不足以测试假设，应在训练前重新登记新参数，而非训练后根据test挑值。初步操作性门槛：平均至少25%有效像素达到σ≥2；此25%是实验约定，不是视觉理论常数。
3. 服务器开始任何GPU作业前重新核查可用物理GPU、其它用户进程、NUMA拓扑、内存EDAC/MCE/SIGBUS以及磁盘；按当时无故障资源选卡并绑定同一健康NUMA，不沿用历史“计数清零=修复”的假设。不修改全局环境，不抢占别人的GPU。先单图/单batch CPU与有限GPU smoke，再启动正式训练。

## 5. 训练预算与可复现性

首选统一配方：ResNet18随机初始化、200类头、224输入、全局batch64、SGD momentum0.9/weight decay 5e−4、初始学习率0.025、前5轮warmup随后cosine衰减、交叉熵、固定200轮。有效batch不足时使用梯度累积保持64，并**所有组一起**调整；不因单组运行情况增减训练轮数。输出最后一轮权重为主要对比，各自dev最优权重只作次要敏感性分析。CUB样本少，从零训练可能过拟合；先看A的train/dev曲线、逐类表现和是否真正收敛，若配方明显失效，先统一修订A/B/C/D的共同配方并重新冻结，不能只替D调参。

开发阶段先用模型种子2027分别跑A/B/C/D；若D落在接近A的合理范围或D优于C，A/C/D再用2005与42各重跑一次。若D首次大幅劣于A，至少补一个独立种子并核查鸟体保护/数据流水线后才能作负面判断。B主要用于诊断，若其结果成为核心结论则同样补足种子。对同一模型种子，四组尽可能共享初始权重、样本顺序和增强抽样；保存代码提交/哈希、环境版本、配置、种子、清单SHA、每轮日志、last/best权重和处理图样例。项目产物只放本次`configs/src/runs/reports`。

## 6. 评价、统计与防止误判

主指标是Top-1和逐类平均Top-1；同时报告Top-5、每类准确率、A与D的逐图翻转（原来对→错、错→对）、交叉熵、学习曲线、训练耗时与**预处理+网络**端到端推理延迟。按框面积三分位、位置偏心、类别及可见部位分层。掩膜只作事后诊断：分别报告严格白像素、`≥153`和`>0`的鸟体像素在`σ=0`或`σ≤1`区域中的比例，避免选一个阈值暗中制造保护率。记录有效背景的清晰面积和实际处理量。不要把模糊比例当成输入像素/FLOPs节省量；四组ResNet18的密集计算相同，B/C/D还增加预处理成本。

预登记主比较为匹配训练的D相对A的Top-1差值，建议“可接受的绝对下降”δ=1.0个百分点；仅在**单侧95%配对区间下界高于−1.0点**且处理剂量达标时称满足这条非劣门槛。dev为1,000图，精细差异可能证据不足；配置锁定后再在官方test 5,794图作最终一次性判断。按图像并按类别分层bootstrap估计样本不确定性，跨随机种子的差异单独报告，不能把3个种子×N图伪装成3N个独立样本。D>C若成立，仍只能说明本设置下保留低频外围上下文更有利，须检查处理剂量和边缘差异；D>A也不能直接归因于“模糊”，因为D额外知道GT框位置。

另做A、D的2×2交叉评价（A训练→原图/D图；D训练→原图/D图）。冻结A在D图上失分主要是分布偏移诊断，不能代替D匹配训练。所有GT框驱动的dev/test条件必须标成Oracle；无框部署性能目前仍未知。

## 7. 阶段门槛与后续顺序

- 若D在足够背景处理量下、跨种子稳定接近A，且框内/掩膜鸟体几乎未受损，则进入**径向单次注视**：GT框中心R=48、过渡32、σmax4，对比图像中心及同清晰面积随机中心；再只做有限R=32/48/64一维检查。径向实验须单列，不把其负结果解释成“背景必需”。
- 若D与C相当，不宣称外围低频背景必要；优先检查更简单的目标区域输入。如果Crop-Resize更强，单独研究目标放大收益，而不将其作为背景模糊的证据。
- 若D稳定显著劣于A，先查可见鸟部位被模糊、30异常框、较小/偏心目标和训练配方；排除实现问题后对当前方法作no-go，停止大网格、更多backbone和盲目加模糊强度。
- **真正省计算**是第二研究阶段：实际减少分类器处理的像素/token，并同预算比较普通降分辨率与目标裁剪；若只是把多尺度图上采样回224再喂普通ResNet18，不能声称FLOPs下降。预测注视点、多次注视及Oxford-IIIT Pet复验均在更后面。
